## 02. 테스트 결과 정의

| 결과 | 설명 |
| --- | --- |
| PASS | 기대 결과와 일치 |
| FAIL | 기대 결과와 불일치 |
| BLOCKED | 선행 기능 또는 환경 문제로 수행 불가 |
| NOT RUN | 테스트 미수행 |
| N/A | 테스트 대상에 해당하지 않음 |

## 03. 결함 심각도

| 심각도 | 설명 |
| --- | --- |
| Critical | 게임 실행 불가, 저장 데이터 손실, 주요 기능 전체 중단 |
| Major | 핵심 조작, 충돌, 정산 등 주요 기능 오류 |
| Normal | 일부 기능 및 화면 표시 오류 |
| Minor | 경미한 디자인 및 문구 오류 |
| Enhancement | 사용성 또는 밸런스 개선 사항 |
