### 문서 검토 중 발견한 일정 상충

- 기본 튜토리얼은 GAME_POLICY의 Phase 01, FUNCTION_SPEC의 FN-034, UI_UX_SPEC의 SCR-013에서 최초 시작 전에 제공하도록 정의한다.
- DEV_CHECKLIST에서는 DEV-024 튜토리얼을 Sprint 06에 배정한다.
- Sprint 01의 시작 흐름은 FN-004의 필수 튜토리얼 완료 조건과 연결된다.
- 이번 작업에서는 사용자가 요청한 간단한 시작 흐름을 유지하기 위해 최초 실행 시 텍스트 안내를 표시하고 확인 후 카운트다운으로 진행한다. 체험형 튜토리얼은 구현하지 않는다.
- 다음 문서 개정 시 DEV-024 일정을 Sprint 01/06 중 하나로 일치시킬 필요가 있다.

카운트다운은 표시 시작 후 3초에 GO와 함께 플레이를 시작하도록 구현했다. 이는 GAME_POLICY의 시작 시간 3초와 FUNCTION_SPEC의 `3 → 2 → 1 → GO` 표시를 함께 만족하는 기준이다.
