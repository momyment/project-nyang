# 02. 공통 기능 처리 원칙

- 게임 진행 상태를 단일 기준으로 관리
- PLAYING 상태에서만 거리, 점수, 이동 및 충돌 처리
- 시간 기반 로직은 프레임 수가 아닌 실제 게임 진행 시간 기준으로 계산
- 브라우저 포커스 이탈 시 게임 정지 및 입력 초기화
- 동일 아이템 및 장애물의 중복 처리 방지
- 게임 종료 및 보상 정산 로직의 중복 실행 방지
- 밸런스 관련 수치는 별도 설정 데이터로 관리
- UI 표시용 데이터와 실제 게임 데이터를 일치시킴
- 신규 기능 추가 시 기존 기능과의 영향도 검토

# 03. 초기화 및 시작 기능

## FN-001. 게임 초기화 및 로딩

- 연관 화면: SCR-001
- 실행 조건: 최초 접속 또는 브라우저 새로고침
- 입력: 게임 설정, 이미지 및 필수 리소스
- 출력: 게임 실행 가능 상태

처리 절차:

1. 게임 환경 초기화
2. 필수 리소스 목록 확인
3. 리소스 로딩
4. 저장 데이터 로딩
5. 필수 데이터 유효성 검증
6. 화면 및 입력 시스템 초기화
7. 메인 화면 진입

예외 처리:

- 필수 리소스 누락 시 메인 화면 진입 차단
- 실패 시 다시 시도 버튼 표시
- 재시도 중 기존 로딩 요청 중복 실행 제한
- 저장 데이터 오류는 FN-035 정책에 따라 처리

완료 기준: 필수 리소스 로딩 완료 후 정상적으로 메인 화면에 진입한다.

## FN-002. 저장 데이터 불러오기

- 연관 화면: SCR-001
- 연관 정책: GAME_POLICY 16장

처리 절차:

1. LocalStorage 저장 데이터 조회
2. 최초 실행 여부 확인
3. 저장 데이터 구조 및 값 검증
4. 누락된 항목 기본값 적용
5. 버전 확인 및 필요 시 마이그레이션
6. 게임 상태에 저장 데이터 반영

예외 처리:

- 저장 데이터 없음: 기본값 생성
- 일부 항목 누락: 해당 항목 보완
- 전체 데이터 손상: 복구 또는 초기화 안내
- 저장소 접근 불가: 사용자 안내 후 저장 불가 모드 적용

완료 기준: 기존 기록 및 재화가 정상적으로 반영되며, 초기 실행도 가능하다.

## FN-003. 메인 화면

- 연관 화면: SCR-002
- 실행 조건: 게임 초기화 완료 또는 메인 화면 이동

기능:

- 선택 캐릭터 표시
- 보유 재화 표시
- 최고 점수 및 최장 거리 표시
- 게임 시작
- 조작 안내 표시

예외 처리:

- 기록이 없는 경우 0 표시
- 미구현 메뉴 숨김
- 게임 시작 요청 중복 실행 차단

## FN-004. 게임 시작

- 연관 화면: SCR-002, SCR-013, SCR-009
- 연관 정책: START-001~010

실행 조건:

- 리소스 로딩 완료
- 게임 시작 버튼 선택
- 필수 튜토리얼 확인 완료
- 모바일 가로 모드 충족

초기 데이터:

| 항목 | 초기값 |
| --- | --- |
| 플레이 ID | 신규 고유 ID |
| 체력 | 3 |
| 이동 거리 | 0 |
| 점수 | 0 |
| 획득 생선 | 0 |
| 난이도 | LV.1 |
| 속도 배율 | 1.0 |
| 점프 횟수 | 0 |
| 무적 상태 | false |
| 정산 상태 | 미정산 |

처리:

- 이전 플레이의 오브젝트 및 타이머 제거
- 신규 플레이 데이터 생성
- 캐릭터 위치 및 상태 초기화
- 카운트다운 실행
- 카운트다운 완료 후 PLAYING 상태 전환

예외 처리:

- 시작 버튼 연속 입력 무시
- 이전 플레이 결과 데이터와 신규 플레이 데이터 분리
- 기존 누적 재화 및 최고 기록 유지

## FN-005. 카운트다운

- 적용 상황: 신규 게임 시작 / 일시정지 후 재개
- 기본 시간: 3초
- 표시: 3 → 2 → 1 → GO

처리:

- 카운트다운 중 게임 오브젝트 정지
- 캐릭터 조작 차단
- 거리 및 점수 증가 중단
- 완료 시 PLAYING 상태 전환

예외 처리:

- 카운트다운 중 화면 포커스 이탈 시 일시정지
- 재개 시 카운트다운 처음부터 실행
- 기존 입력값을 초기화하여 재개 직후 의도하지 않은 동작 방지

# 04. 캐릭터 이동 및 조작

## FN-006. 자동 달리기

- 연관 정책: MOVE-001~007
- 실행 조건: PLAYING 상태

| 항목 | 초기 기준값 |
| --- | --- |
| 기준 해상도 | 1280 × 720 |
| 캐릭터 기준 X 좌표 | 320px |
| 지면 높이 | Y=572px 가안 |
| 기본 이동 속도 | 300px/s |
| 최대 이동 속도 | 540px/s |

처리:

- 캐릭터 가로 위치 고정
- 장애물 및 지면을 좌측으로 이동
- 난이도에 따른 이동 속도 적용
- 실제 이동량을 거리 계산 기능에 전달

예외 처리:

- 일시정지 중 이동 중단
- 게임 종료 후 이동 중단
- 프레임 저하로 인한 과도한 이동 방지

## FN-007. 배경 스크롤

- 연관 화면: SCR-009
- 연관 정책: MOVE-005

| 레이어 | 이동 속도 비율 가안 |
| --- | --- |
| 하늘 | 0.05 |
| 원거리 산 | 0.15 |
| 중거리 나무 | 0.35 |
| 근거리 오브젝트 | 0.65 |
| 지면 | 1.00 |

현재 게임 진행 속도에 레이어별 비율을 곱해 이동 속도를 적용한다.

처리:

- 배경 이미지를 연속적으로 반복
- 반복 경계에 공백이 발생하지 않도록 구성
- 난이도 변경 시 각 레이어 속도 비율 유지
- 게임 재시작 시 배경 위치 초기화

Phase 01에서는 임시 배경을 활용할 수 있으며 최종 패럴랙스 리소스는 Phase 02에서 적용한다.

## FN-008. 1단 점프

- 연관 정책: JUMP-001~009
- 입력: Space / ↑ / 모바일 점프 버튼

실행 조건:

- PLAYING 상태
- 캐릭터가 지면에 위치
- 체력 1 이상
- 신규 점프 입력 발생

초기 설정값:

| 항목 | 가안 |
| --- | --- |
| 중력 | 1,500px/s² |
| 1단 점프 수직 속도 | -600px/s |
| 최대 상승 높이 | 약 120px |
| 최대 점프 횟수 | 2회 |

처리:

1. 입력 유효성 확인
2. 슬라이딩 중인 경우 슬라이딩 해제
3. 캐릭터 수직 속도 적용
4. 점프 횟수 1 증가
5. JUMP 상태 전환

예외 처리:

- 입력을 계속 유지해도 자동 반복하지 않음
- 일시정지 및 종료 상태에서 무시
- 지면에 있지 않은 경우 FN-009 조건으로 처리

## FN-009. 2단 점프

- 실행 조건: 공중 상태이며 현재 점프 횟수 1회

초기 수직 속도: -540px/s 가안

처리:

- 기존 수직 속도를 2단 점프 속도로 변경
- 점프 횟수를 2회로 변경
- DOUBLE_JUMP 상태 전환
- 상승 및 하강 중 모두 사용 가능

예외 처리:

- 착지 전 3번째 점프 입력 무시
- 키 자동 반복 이벤트로 인한 2단 점프 실행 방지
- 일시정지 해제 시 자동 추가 점프 방지

## FN-010. 슬라이딩

- 연관 정책: SLIDE-001~010
- 입력: ↓ / 모바일 슬라이딩 버튼

실행 조건:

- PLAYING 상태
- 캐릭터가 지면에 위치
- 슬라이딩 입력 유지

처리:

- SLIDE 상태 전환
- 캐릭터 이미지 변경
- 충돌 영역 높이를 일반 상태의 50% 수준으로 축소
- 이동 속도는 기존 값 유지
- 입력 유지 중 슬라이딩 유지

종료 조건:

- 버튼 해제 및 최소 유지 시간 0.2초 충족
- 점프 입력 발생
- 게임 종료
- 입력 초기화

예외 처리:

- 공중에서 입력 무시
- 점프와 슬라이딩 동시 입력 시 점프 우선
- 점프 입력은 최소 슬라이딩 유지 시간보다 우선
- 포커스 이탈 시 슬라이딩 입력 초기화

## FN-011. 착지 및 상태 복귀

실행 조건: 공중 상태의 캐릭터가 지면에 도달

처리:

- 캐릭터 발 기준점을 지면에 맞춤
- 수직 이동 속도 0 적용
- 점프 횟수 0으로 초기화
- RUN 상태 전환
- 일반 상태의 충돌 영역 적용

예외 처리:

- 지면 아래로 캐릭터가 이동하지 않도록 보정
- 착지 이벤트 중복 실행 방지
- 게임 오버 상태에서는 상태 복귀 제한

# 05. 장애물 및 충돌

## FN-012. 장애물 생성

- 연관 정책: OBS-P01~08

| 장애물 ID | 장애물 | 초기 충돌 크기 |
| --- | --- | --- |
| OBS-001 | 돌멩이 | 50 × 40px |
| OBS-002 | 통나무 | 90 × 85px |
| OBS-003 | 나뭇가지 | 너비 100px, 하단 높이 50px 가안 |

처리:

1. 현재 난이도 확인
2. 해당 난이도에서 허용되는 장애물 패턴 조회
3. 기존 장애물 및 예상 도착 시간 확인
4. 회피 가능 여부 검증
5. 안전한 패턴 내 무작위 선택
6. 화면 우측 외부에 장애물 생성

예외 처리:

- 게임 시작 후 최소 3초간 생성 금지
- 최초 장애물은 낮은 지상형으로 제한
- 생성 간격보다 회피 가능 조건을 우선 적용
- 기존 장애물과 중첩되는 경우 생성 보류
- 안전한 패턴이 없는 경우 다음 생성 기회로 연기

## FN-013. 장애물 이동 및 제거

처리:

- 현재 게임 진행 속도에 맞춰 좌측 이동
- 화면 좌측을 완전히 벗어난 장애물 제거
- 제거된 장애물의 충돌 검사 제외
- 게임 종료 및 재시작 시 모든 장애물 정리

반복 플레이 시 오브젝트가 누적되지 않도록 재사용 또는 제거 방식을 적용한다.

## FN-014. 충돌 판정

- 연관 정책: HIT-001~008
- 실행 조건: PLAYING 상태

## FN-019. 이동 거리 계산

- 연관 정책: DIST-001~007

거리 계산:

누적 이동량(px) ÷ 30 = 이동 거리(m)

화면 표시 시 소수점 이하 버림.

- 기본 속도 300px/s에서 초당 10m 증가
- 난이도 변경에 따라 거리 증가량 변경
- 실제 게임 진행에 반영된 이동량을 사용
- 일시정지 및 종료 후 증가 금지
- 프레임 수에 따른 거리 증가 방식 금지

## FN-020. 점수 계산

점수 = 정수 이동 거리 + 획득 생선 수량 × 10

처리:

- 거리 및 아이템 획득 시 점수 갱신
- 소수점 이하 점수 미표시
- 장애물 충돌 시 점수 차감 없음
- 점수 계산 결과를 단일 기준값으로 관리
- 게임 종료 시 최종 점수 확정

- 완료 후 신규 게임 카운트다운 진행
- 이후 게임 시작에서는 자동 노출하지 않음
- 메인 화면에서 다시 보기 가능

## FN-035. 오류 및 복구 처리

| 오류 유형 | 처리 |
| --- | --- |
| 이미지 로딩 실패 | 재시도 또는 필수 리소스 오류 안내 |
| 저장 데이터 누락 | 누락 항목 기본값 적용 |
| 저장 데이터 손상 | 재시도 및 초기화 안내 |
| 저장소 접근 불가 | 저장 불가 안내 및 세션 플레이 허용 |

| 비정상적인 게임 상태 | 진행 중단 후 안전한 화면 이동 |
| 브라우저 새로고침 | 진행 중 플레이 폐기 및 기존 저장 데이터 로딩 |
| 중복 게임 시작 | 추가 요청 무시 |
| 중복 정산 | 기존 정산 결과 유지 |

사용자의 기존 저장 데이터는 명시적인 확인 없이 삭제하지 않는다.

# 16. 게임 처리 순서

PLAYING 상태에서 다음 순서로 게임 진행 로직을 처리한다.

1. 입력 이벤트 확인
2. 캐릭터 이동 및 물리 연산
3. 배경 및 장애물 이동
4. 아이템 이동
5. 이동 거리 계산
6. 충돌 판정 및 체력 처리
7. 체력 0 여부 확인
8. 생존 상태에서 아이템 획득 처리
9. 점수 계산
10. 난이도 확인 및 변경
11. 신규 오브젝트 생성 여부 확인
12. 화면 및 애니메이션 갱신

체력 0으로 종료되는 경우 해당 시점의 최종 거리와 기존 획득량으로 점수를 확정하고 후속 아이템 획득 및 생성 처리는 실행하지 않는다.
