# 02. 게임 콘셉트

## 2.1 핵심 콘셉트

**작은 발걸음으로 떠나는 커다란 모험**

귀여운 반려동물 캐릭터와 함께 동화 속 세상을 달리며 간식을 모으고, 새로운 친구와 의상을 수집하는 힐링 러닝 게임.

복잡한 조작 없이 누구나 쉽게 시작할 수 있으며, 플레이에 익숙해질수록 새로운 장애물과 난이도에 도전할 수 있도록 구성한다.

## 2.2 게임 스토리

평화로운 마을에 살고 있던 고양이.

어느 날 창문 너머로 반짝이는 나비 한 마리를 발견하고, 호기심에 이끌려 집 밖으로 첫 모험을 떠난다.

푸른 숲, 벚꽃이 흩날리는 마을, 햇살 가득한 바닷가, 단풍으로 물든 길과 눈 내리는 겨울 마을까지.

새로운 세상을 달리며 맛있는 간식을 모으고, 다양한 친구들을 만나면서 자신만의 모험을 완성해 나간다.

## 2.3 핵심 재미 요소

| 요소 | 내용 |
| --- | --- |
| 조작 | 점프, 2단 점프, 슬라이딩을 활용한 장애물 회피 |
| 탐험 | 다양한 테마의 스테이지 플레이 |
| 수집 | 캐릭터, 코스튬, 재화 획득 |
| 성장 | 캐릭터별 능력 강화 |
| 도전 | 최고 기록 갱신 및 스테이지 클리어 |
| 힐링 | 따뜻한 그래픽과 음악, 귀여운 캐릭터 연출 |

# 03. 게임 플레이

## 3.1 기본 플레이 방식

- 캐릭터는 자동으로 달리며 사용자가 이동 방향을 별도로 조작하지 않는다.
- 사용자는 점프, 2단 점프, 슬라이딩을 통해 장애물을 회피한다.
- 이동 중 간식과 특수 아이템을 획득할 수 있다.
- 장애물과 충돌하면 체력이 감소한다.
- 체력이 모두 소진되면 게임이 종료된다.
- 플레이 결과에 따라 점수와 재화를 획득한다.
- 획득한 재화는 캐릭터, 코스튬, 능력 강화 등에 사용한다.

## 3.2 조작 방식

| 기능 | PC | 모바일 |
| --- | --- | --- |
| 달리기 | 자동 | 자동 |
| 점프 | Space / ↑ | 점프 버튼 |
| 2단 점프 | 공중에서 점프 재입력 | 공중에서 점프 버튼 재터치 |
| 슬라이딩 | ↓ | 슬라이딩 버튼 |
| 일시정지 | ESC | 일시정지 버튼 |

## 3.3 게임 모드

### A. 무한 달리기 모드

- 체력이 모두 소진될 때까지 달리는 방식
- 이동 거리에 따라 속도 및 장애물 난이도 증가
- 이동 거리와 획득 아이템에 따라 점수 산정
- 개인 최고 점수 및 최장 거리 기록 저장
- 반복 플레이를 통한 재화 획득

### B. 스테이지 모드

- 각 스테이지에 설정된 목표 거리까지 도달하는 방식
- 스테이지별 배경, 장애물 및 난이도 차등 적용
- 목표 거리 도달 시 스테이지 클리어
- 클리어 결과에 따라 보상 지급
- 이전 스테이지 클리어를 통한 다음 스테이지 해금

## 3.4 기본 플레이 순환 구조

게임 시작 → 캐릭터 선택 → 게임 모드 선택 → 달리기 및 장애물 회피 → 보상 획득 → 캐릭터 수집 및 강화 → 새로운 모험 시작

# 04. 캐릭터 시스템

## 4.1 캐릭터 구성 방향

실제 반려동물을 모티브로 한 캐릭터와 게임 세계관에 맞춰 제작된 가상의 캐릭터를 함께 구성한다.

캐릭터별 외형, 표정, 애니메이션 및 능력에 차이를 두어 수집과 선택의 재미를 제공한다.

## 4.2 캐릭터 유형

| 유형 | 설명 |
| --- | --- |
| 기본 캐릭터 | 최초 게임 시작 시 무료 제공 |
| 실제 반려동물 캐릭터 | 실제 반려동물의 외형과 특징을 반영 |
| 가상 캐릭터 | 게임 세계관에 맞춰 제작한 캐릭터 |
| 특별 캐릭터 | 특정 조건을 달성하면 해금되는 캐릭터 |

초기에는 흰색 장모 페르시안 고양이를 기본 캐릭터로 제작한다.

## 4.3 캐릭터 능력치

| 능력치 | 설명 |
| --- | --- |
| 체력 | 장애물 충돌 시 생존 가능 횟수 |
| 점프력 | 점프 높이 및 공중 이동 능력 |
| 회복력 | 체력 회복 아이템의 효과 |
| 수집력 | 간식 및 재화 획득 보너스 |
| 특수 능력 | 캐릭터별 고유 능력 |

캐릭터별 능력 차이는 적용하되, 특정 캐릭터만으로 모든 콘텐츠를 쉽게 클리어할 수 없도록 밸런스를 구성한다.

## 4.4 캐릭터 애니메이션

- 대기
- 달리기
- 점프
- 2단 점프
- 슬라이딩
- 착지
- 장애물 충돌
- 무적 상태
- 게임 오버
- 스테이지 클리어
- 기쁨 및 보상 획득

## 4.5 캐릭터 강화

- 플레이를 통해 획득한 재화로 능력 강화
- 능력별 강화 단계 적용
- 강화 단계별 필요 재화 증가
- 최대 강화 단계 설정
- 캐릭터별 강화 정보 개별 저장

세부 강화 비용 및 최대 강화 단계는 게임 정책서에서 정의한다.

# 05. 코스튬 시스템

캐릭터의 외형을 변경할 수 있는 의상 및 액세서리 수집 기능을 제공한다.

| 카테고리 | 예시 |
| --- | --- |
| 기본 의상 | 스카프, 리본 |
| 봄 테마 | 벚꽃, 딸기 |
| 여름 테마 | 밀짚모자, 수영복 |
| 가을 테마 | 베레모, 도토리 |
| 겨울 테마 | 산타복, 목도리 |
| 판타지 테마 | 마법사, 요정 |
| 특별 테마 | 꿀벌, 우주비행사 |

코스튬은 기본적으로 외형 변경을 목적으로 하며, 능력치와 분리한다. 이를 통해 사용자가 능력치와 관계없이 원하는 디자인을 선택할 수 있도록 한다.

# 06. 스테이지 시스템

## 6.1 기본 스테이지

| STAGE | 테마 | 주요 장애물 | 기본 난이도 |
| --- | --- | --- | --- |
| 01 | 초록빛 숲속 | 돌멩이, 통나무, 나뭇가지 | ★☆☆☆☆ |
| 02 | 벚꽃 마을 | 화분, 개울, 벌 | ★★☆☆☆ |
| 03 | 여름 바닷가 | 꽃게, 모래성, 파도 | ★★★☆☆ |
| 04 | 단풍 숲 | 버섯, 낙엽 더미, 도토리 | ★★★★☆ |
| 05 | 크리스마스 마을 | 눈사람, 얼음, 선물 상자 | ★★★★★ |

## 6.2 스테이지 구성 요소

- 스테이지별 전용 배경 일러스트
- 스테이지별 지형 및 장애물
- 스테이지별 배경음악
- 테마에 맞는 환경 애니메이션
- 아이템 등장 패턴
- 스테이지별 난이도 설정

## 6.3 환경 연출

- 숲속: 바람에 흔들리는 풀과 나비
- 벚꽃 마을: 흩날리는 벚꽃잎
- 바닷가: 움직이는 파도와 갈매기
- 단풍 숲: 떨어지는 단풍잎
- 크리스마스 마을: 내리는 눈과 반짝이는 조명

환경 연출은 실제 장애물과 시각적으로 명확하게 구분하여 플레이를 방해하지 않도록 한다.

# 07. 장애물 시스템

## 7.1 장애물 분류

| 유형 | 예시 | 회피 방법 |
| --- | --- | --- |
| 낮은 지상 장애물 | 돌멩이, 버섯 | 점프 |
| 높은 지상 장애물 | 통나무, 눈사람 | 점프 또는 2단 점프 |
| 공중 장애물 | 나뭇가지, 벌 | 슬라이딩 |
| 낙하 구간 | 개울, 끊어진 길 | 점프 또는 2단 점프 |
| 이동형 장애물 | 꽃게, 움직이는 벌 | 타이밍에 맞춰 회피 |
| 낙하형 장애물 | 떨어지는 도토리 | 위치 및 타이밍에 맞춰 회피 |

## 7.2 장애물 생성 원칙

- 초기에는 단순한 장애물 위주로 등장
- 진행 거리에 따라 복합 장애물 등장
- 사용자에게 충분한 회피 반응 시간 제공
- 회피가 불가능한 장애물 조합 생성 제한
- 장애물과 배경 오브젝트의 시각적 구분
- 실제 캐릭터 외형에 맞는 충돌 영역 적용

# 08. 아이템 및 재화 시스템

## 8.1 플레이 아이템

| 아이템 | 효과 |
| --- | --- |
| 생선 | 기본 재화 및 점수 획득 |
| 닭고기 | 추가 점수 획득 |
| 하트 | 체력 회복 |
| 자석 | 일정 시간 주변 간식 자동 획득 |
| 보호막 | 장애물 충돌 1회 방어 |
| 별 | 일정 시간 점수 획득량 증가 |
| 부스터 | 일정 시간 무적 상태로 고속 질주 |
| 보물상자 | 게임 종료 후 랜덤 보상 지급 |

## 8.2 재화 시스템

초기 버전에서는 생선을 기본 재화로 사용한다.

재화 사용처:

- 캐릭터 해금
- 코스튬 구매
- 캐릭터 능력 강화
- 상점 내 아이템 구매

스테이지 해금은 기본적으로 이전 스테이지 클리어 조건을 사용한다.

유료 재화 및 실제 결제 기능은 초기 개발 범위에서 제외한다.

# 09. 체력 및 점수 시스템

## 9.1 체력

- 기본 캐릭터 체력 3칸
- 장애물 충돌 시 체력 1칸 감소
- 충돌 후 일정 시간 무적 상태 적용
- 체력 회복 아이템을 통한 회복
- 최대 체력을 초과한 회복 제한
- 체력이 0이 되면 게임 종료

## 9.2 점수 기준

초기 밸런스 테스트를 위한 가안으로 적용한다.

| 항목 | 기준 |
| --- | --- |
| 이동 거리 | 1m당 1점 |
| 생선 획득 | 1개당 10점 |
| 닭고기 획득 | 1개당 50점 |
| 충돌 후 무적 시간 | 2초 |
| 최고 기록 | 자동 저장 |

## 9.3 결과 화면

- 최종 획득 점수
- 총 이동 거리
- 획득한 생선 수량
- 추가 획득 보상
- 최고 기록 갱신 여부
- 스테이지 클리어 여부
- 다시 시작 버튼
- 메인 화면 이동 버튼

# 10. 난이도 시스템

## 10.1 기본 방향

초보 사용자도 쉽게 플레이할 수 있도록 시작 난이도를 낮게 설정한다.

플레이가 진행될수록 이동 속도, 장애물 종류, 등장 빈도 및 배치 패턴을 변경하여 자연스럽게 난이도를 높인다.

## 10.2 무한 달리기 난이도

| 구간 | 이동 속도 배율(가안) | 난이도 |
| --- | --- | --- |
| 0~500m 미만 | 1.0배 | 입문 |
| 500~1,000m 미만 | 1.2배 | 쉬움 |
| 1,000~2,000m 미만 | 1.4배 | 보통 |
| 2,000~3,000m 미만 | 1.6배 | 어려움 |
| 3,000m 이상 | 1.8배 | 도전 |

## 10.3 난이도 설계 원칙

- 시작 구간에서 충분한 조작 적응 시간 제공
- 장애물의 등장 패턴을 통해 자연스럽게 조작 학습
- 이동 속도 증가에 따른 회피 가능 여부 검증
- 무작위 장애물 조합으로 인한 불합리한 게임 오버 방지
- 반복 플레이 및 캐릭터 강화를 통한 기록 향상 유도

| SCR-008 | 상점 | 캐릭터, 아이템 구매 |
| SCR-009 | 인게임 | 실제 게임 플레이 |
| SCR-010 | 일시정지 | 계속하기, 재시작, 종료 |

# 12. 그래픽 및 사운드 디자인

## 12.1 그래픽 방향

- 파스텔톤 기반의 손그림풍 일러스트
- 둥글고 부드러운 캐릭터 외형
- 따뜻한 색감과 동화적인 배경
- 과도하게 자극적이지 않은 시각 효과
- 귀여운 표정 및 자연스러운 캐릭터 움직임
- 통일된 UI 및 아이콘 디자인
- 배경과 플레이 오브젝트 간 명확한 시인성 확보

## 12.2 배경 연출

여러 개의 배경 레이어에 서로 다른 이동 속도를 적용하는 패럴랙스 스크롤 방식을 사용한다.

- 원거리: 하늘, 구름, 산
- 중거리: 숲, 건물, 나무
- 근거리: 꽃, 풀, 장식 오브젝트
- 플레이 영역: 지면, 캐릭터, 장애물, 아이템

## 12.3 사운드

- 스테이지별 편안하고 경쾌한 배경음악
- 캐릭터 점프 효과음
- 간식 획득 효과음
- 장애물 충돌 효과음
- 아이템 사용 효과음
- 게임 오버 및 스테이지 클리어 효과음
- 버튼 선택 효과음

배경음악과 효과음은 각각 ON/OFF 설정을 제공한다.

# 13. 데이터 저장

초기 버전은 별도의 서버 및 회원가입 기능 없이 브라우저 로컬 저장소를 활용한다.

| 저장 항목 | 내용 |
| --- | --- |
| 사용자 재화 | 보유 생선 수량 |
| 캐릭터 정보 | 보유 및 해금 상태 |
| 캐릭터 강화 | 캐릭터별 강화 단계 |
| 코스튬 정보 | 보유 및 착용 상태 |
| 스테이지 정보 | 해금 및 클리어 상태 |
| 게임 기록 | 최고 점수 및 최장 거리 |
| 사용자 설정 | 음악 및 효과음 설정 |
| 튜토리얼 | 완료 여부 |

브라우저 종료 및 재접속 후에도 데이터가 유지되도록 한다. 단, 브라우저 저장 데이터 삭제 또는 다른 기기에서 접속하는 경우 데이터가 유지되지 않을 수 있다.
