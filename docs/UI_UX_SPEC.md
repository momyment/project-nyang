## 1.4 공통 인터랙션

- 버튼 선택 시 시각적 피드백 제공
- 화면 전환 중 중복 입력 차단
- 팝업 표시 중 하위 화면 입력 차단
- PC 키보드 조작 시 브라우저 스크롤 방지
- 모바일 터치 시 게임 영역 확대 및 스크롤 방지
- 데이터 처리 실패 시 사용자 안내 제공
- 비활성화된 메뉴는 선택 불가
- 화면 전환 애니메이션은 약 0.2~0.3초 기준 적용
- 게임 플레이 중 화면 전환 효과로 인한 조작 지연 방지

# 04. SCR-001 로딩 화면

## 4.1 화면 목적

게임 실행에 필요한 리소스 및 저장 데이터를 불러오는 화면.

## 4.2 UI 구성

| UI ID | 구성 요소 | 표시 및 동작 |
| --- | --- | --- |
| UI-001-01 | 게임 로고 | 화면 중앙 상단 |
| UI-001-02 | 캐릭터 이미지 | 화면 중앙 |
| UI-001-03 | 로딩 진행 바 | 실제 리소스 로딩 진행률 표시 |
| UI-001-04 | 로딩 진행률 | 0~100% |
| UI-001-05 | 안내 문구 | 모험을 준비하고 있어요! |
| UI-001-06 | 다시 시도 | 로딩 실패 시 표시 |

## 4.3 화면 동작

- 필수 리소스 및 저장 데이터 로딩
- 로딩 진행률에 따른 진행 바 업데이트
- 정상 로딩 완료 시 메인 화면 자동 이동
- 필수 리소스 로딩 실패 시 오류 팝업 표시
- 저장 데이터 오류 발생 시 복구 또는 초기화 안내
- 로딩 중 사용자 조작 제한

연관 정책: COM-001~010, DATA 저장 정책, POP-004, POP-006

- 캐릭터 대기 애니메이션 적용은 Phase 02부터 제공

## 12.3 정보 표시 정책

- 체력: 보유 체력을 채워진 하트, 감소한 체력을 빈 하트로 표시
- 점수: 현재 점수를 실시간 갱신
- 거리: 소수점 이하를 제외한 정수 m 단위 표시
- 생선: 현재 플레이 중 획득한 수량만 표시
- 보유 재화: 인게임에서 별도 표시하지 않음
- 카운트다운: 3 → 2 → 1 → GO
- 난이도 변경: 잠시 안내 후 자동 제거
- PC에서는 모바일 조작 버튼을 기본적으로 숨김

## 12.4 게임 중 시각적 피드백

| 이벤트 | 표현 방식 |
| --- | --- |
| 생선 획득 | 반짝임 및 +10점 |
| 장애물 충돌 | 짧은 피격 효과 |
| 체력 감소 | 하트 감소 애니메이션 |
| 무적 상태 | 캐릭터 반투명 점멸 또는 테두리 효과 |
| 2단 점프 | 작은 별 또는 바람 효과 |
| 슬라이딩 | 먼지 또는 잔디 효과 |
| 난이도 증가 | 짧은 안내 문구 |
| 게임 종료 | 캐릭터 종료 애니메이션 |

효과는 게임의 시인성을 방해하지 않는 범위에서 적용하며, 필수 기능 이후 Phase 02에서 완성도를 개선한다.

# 18. 화면 접근성 및 사용성

- 모든 주요 버튼에 텍스트 또는 의미가 명확한 아이콘 제공
- 잠금 및 비활성화 상태를 색상만으로 구분하지 않음
- 작은 화면에서도 텍스트 식별 가능
- 체력과 보상 수량의 실시간 식별 가능
- 점프 및 슬라이딩 버튼의 터치 영역 중첩 방지
- 키보드로 기본 메뉴 선택 가능
- 과도한 화면 흔들림 및 점멸 효과 제한
- 배경과 플레이 오브젝트의 대비 확보

# 19. 화면 개발 완료 기준

- Phase 01 필수 화면 정상 노출
- 화면별 이동 경로 정상 동작
- 지원 해상도에서 UI 잘림 및 중첩 미발생
- PC 및 모바일 조작 정상 동작
- 화면 회전 시 일시정지 및 안내 정상 적용
- 팝업 표시 중 하위 화면 입력 차단
- 반복 화면 전환 시 중복 화면 생성 방지
- 결과 화면과 실제 게임 데이터 일치
- 미구현 기능 및 동작하지 않는 버튼 미노출
