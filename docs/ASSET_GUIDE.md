# 01. 그래픽 콘셉트

## 1.1 기본 방향

동화 속 세상을 달리는 귀여운 반려동물을 중심으로 따뜻하고 편안한 분위기의 2D 횡스크롤 게임을 제작한다.

그래픽은 사실적인 실사 표현이나 픽셀 도트 방식이 아닌 손그림풍 일러스트를 기본으로 한다.

## 1.2 디자인 키워드

- Cozy
- Whimsical
- Storybook
- Hand-drawn
- Soft Pastel
- Warm
- Adorable
- Nature
- Healing
- Adventure

## 1.3 디자인 제외 기준

- 픽셀 도트 그래픽
- 과도하게 사실적인 실사 표현
- 3D 렌더링 특유의 플라스틱 질감
- 지나치게 강한 원색 및 네온 컬러
- 두껍고 거친 검은색 외곽선
- 어둡고 공포스러운 분위기
- 기존 상용 게임 캐릭터와 지나치게 유사한 디자인
- 실제 브랜드 로고 및 무단 사용 이미지
- 불필요한 워터마크 및 생성 이미지 내 문구

# 04. 캐릭터 그래픽

## 4.1 기본 캐릭터

| 항목 | 기준 |
| --- | --- |
| 캐릭터 ID | CHR-001 |
| 캐릭터명 | 추후 확정 |
| 품종 | 페르시안 |
| 기본 털색 | 흰색 |
| 특징 | 회색 머리 무늬, 황금색 눈 |
| 털 길이 | 장모 |
| 체형 | 둥글고 복슬복슬한 형태 |
| 기본 표정 | 호기심 있고 사랑스러운 표정 |
| 이동 방향 | 오른쪽 |
| 인게임 시점 | 측면 중심 |
| 메인 화면 시점 | 정면 또는 3/4 측면 |

실제 반려동물을 모티브로 하며 얼굴형, 털색, 눈동자, 무늬 등의 특징을 유지한다.

실제 사진을 기반으로 최종 캐릭터 디자인 시트를 먼저 제작한다.

현재 임시 적용본은 사용자 반려묘 사진을 참고해 제작했으며, 흰 장모와 황금색 눈, 머리 위 회색 무늬를 반영한다. 세밀한 털 묘사 대신 둥근 형태와 단순한 음영을 쓴 동화풍 캐릭터로 표현하고, 납작한 얼굴이나 과장된 페르시안형으로 만들지 않는다. 임시 애니메이션 시트 `public/assets/characters/nyang-cat-animations.png`는 4열 × 3행이며, 첫째 줄은 달리기, 둘째 줄은 점프, 셋째 줄은 슬라이딩 프레임이다. 최종 디자인 시트가 확정되면 교체한다.

## 5.4 슬라이딩 애니메이션

- 몸체를 지면 가까이 낮추는 자세
- 머리와 귀의 높이를 자연스럽게 낮춤
- 앞발을 앞으로 뻗는 동작
- 꼬리를 몸체 뒤로 자연스럽게 이동
- 캐릭터 외형이 일반 달리기 상태와 동일하게 유지
- 충돌 영역 축소 상태와 이미지 자세 일치
- 유지 입력 중 자연스럽게 반복 재생

## 5.5 피격 및 종료 표현

- 피격 시 놀라거나 당황한 표정
- 과도한 부상 표현 및 유혈 표현 제외
- 게임 오버 시 지쳐 앉거나 아쉬워하는 모습
- 모험 결과 화면에서는 긍정적인 표정 사용
- 무적 상태는 별도 이미지 없이 프로그램 효과로 적용 가능

# 06. 스프라이트 시트 제작 기준

- 모든 프레임의 셀 크기 동일
- 모든 프레임에서 캐릭터 비율 동일
- 실제 투명 배경

## 7.4 배경 이미지 공통 규칙

- 좌우 반복 사용 가능한 이미지 제작
- 반복 연결 시 색상 및 오브젝트 단절 최소화
- 배경에 움직이는 캐릭터, 아이템, 장애물 포함 금지
- 실제 플레이 영역에 장식물이 지나치게 많이 배치되지 않도록 구성
