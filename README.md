# Project NYANG

냥이의 대모험 웹게임 프로토타입입니다. Phaser.js와 Vite로 실행하며, 현재 구현 범위는 Sprint 01~06입니다.

## 실행 방법

Node.js가 설치되어 있고 인터넷 연결이 가능한 환경에서 프로젝트 폴더를 연 뒤 실행합니다.

```bash
npm install
npm run dev
```

터미널에 표시된 로컬 주소(기본 `http://localhost:5173`)를 브라우저에서 엽니다. 코드 변경 없이 테스트만 실행할 때는 `npm test`, 배포용 파일 생성은 `npm run build`를 사용합니다.

## 현재 확인할 내용

1. 동화풍 임시 배경의 메인 화면이 표시됩니다.
2. 처음 실행에서는 텍스트 조작 안내가 먼저 표시됩니다.
3. 안내를 확인하면 3, 2, 1, GO 카운트다운이 나옵니다.
4. GO와 함께 임시 고양이 캐릭터가 자동으로 달리고 배경이 왼쪽으로 움직입니다.
5. Space 또는 ↑로 점프, 공중에서 다시 눌러 2단 점프, ↓를 누르고 있어 슬라이딩합니다.
6. 시작 3초 뒤 첫 돌멩이가 나오고, 충돌하면 하트가 줄며 2초 동안 추가 피해를 받지 않습니다.
7. 생선을 주우면 화면의 생선 수와 점수가 올라갑니다. 이동 거리는 30픽셀마다 1m로 계산됩니다.
8. 500m부터 레벨이 오르고, 캐릭터 달리기 속도와 장애물 패턴이 점차 달라집니다.
9. ESC 또는 화면의 일시정지 버튼으로 멈추고, 계속하기를 누르면 3초 후 이어 달립니다.
10. 체력이 모두 줄면 결과 화면에서 이번 점수·거리·생선과 최고 기록을 확인할 수 있습니다. 정상 종료 보상은 저장되고, 중간에 나가면 저장되지 않습니다.
11. 휴대폰에서는 화면 아래쪽 점프/슬라이딩 버튼을 사용합니다. 가로로 돌려야 플레이할 수 있고, 플레이 중 세로로 돌리면 자동으로 멈춥니다.

GO 이후 약 6초 뒤 첫 장애물이 캐릭터 쪽으로 다가옵니다. 돌멩이와 통나무는 점프로, 공중 나뭇가지는 ↓를 눌러 피할 수 있습니다.

메인 화면과 달리기 화면에 실제 고양이 사진의 특징(흰 장모, 황금색 눈, 머리의 회색 무늬)을 살린 임시 캐릭터를 적용했습니다. 달릴 때는 다리 움직임이 반복되고, 점프와 슬라이딩에서도 각 동작에 맞는 그림으로 바뀝니다. 배경과 장애물은 임시 그래픽이며, 캐릭터 그림과 동작도 최종 디자인 확정 후 교체할 수 있습니다.

개발 환경에서만 F1을 누르면 QA 확인 도구가 표시됩니다. F2는 거리를 500m 늘리고, F3은 생선을 1개 추가하며, F4는 무적 상태를 바꾸고, F5는 게임 종료, F6은 저장 실패 재현, F7은 충돌 영역 표시를 실행합니다. 일반 플레이 화면에서는 이 도구가 나타나지 않습니다.

## 내 컴퓨터에서 실행하기

Node.js를 설치한 뒤 터미널(Windows는 PowerShell)을 열고 프로젝트 폴더에서 아래 명령을 실행합니다.

```bash
npm run dev
```

터미널에 표시된 주소를 브라우저에서 열면 됩니다. 종료하려면 터미널에서 `Ctrl + C`를 누릅니다.
